# Prelaunch security scan — November 12, 2026

## Checks

- `pnpm test`, `pnpm typecheck`, and `pnpm build` passed after the Production launch guard and migration guard changes.
- `pnpm audit --prod --json` reported 4 critical, 9 high, 10 moderate, and 5 low advisories across the lockfile's reported production dependency graph. Many paths include Vitest, Vite, and Tinypool brought in through a Better Auth dependency; those are test/development tools, so the advisory count is not an assertion that each issue is reachable in the deployed app.
- A pattern scan across 484 tracked and unignored files found no recognizable live AWS, GitHub, Slack, Stripe, JWT, or private-key strings. Six generic-secret matches were fixture constants or error-message/test values. Ignored local environment files were deliberately not exported or printed.

## Auth dependency follow-up

The current `@neondatabase/auth@0.7.0-beta` package pins `better-auth@1.7.6`, `@better-auth/core@1.7.6`, and `zod@4.5.4`. The audit includes a critical [Better Auth advisory](https://github.com/better-auth/better-auth/security/advisories/GHSA-965c-763c-88jm) patched in 1.7.7; its stated preconditions include a particular Magic Link plus OAuth configuration. Neon [reports](https://neon.com/blog/whats-new-with-the-neon-backend) that its managed Auth servers were updated to Better Auth 1.7.16 after the November 3 security release. That mitigates the managed server concern, but it does not update this project's pinned client dependency tree or prove every advisory irrelevant. `pnpm view @neondatabase/auth version` still returned `0.7.0-beta` during this scan.

The root `pnpm.overrides` now aligns the Better Auth package family on 1.7.22 and updates the older transitive Better Call, Better Fetch and Zod 4.5.4 releases. This removes the flagged Better Auth advisory. The full test suite, typecheck and build pass. A fresh local production build also passed real agent sign-in, session navigation, review queue and editor checks against the isolated local Neon branch when served at `localhost`. The same check failed at `127.0.0.1`, which is not the configured auth origin; do not treat that host mismatch as an auth regression.

Additional targeted overrides move Vitest 3 to its patched 3.2.6 release, Vite 7 to 7.3.7, Nanoid 3 to 3.3.18, PostCSS to 8.5.18, source-map-js to 1.2.2, and the separate Zod 4.1.11 path to 4.6.7. After these changes, `pnpm audit --prod --json` reports **2 critical, 1 high, 5 moderate and 2 low**. The two critical findings remain in Tinypool 1.1.1, pulled into the reported production tree through Better Auth → Vitest; Tinypool 2.1.2 is a major version update that has not been forced into Vitest 3. The high finding is Zod 3.25.76, whose advisory lists only Zod 4.6.6+ as patched; the board and core currently use Zod 3. These are package-graph findings, not proof of deployed exploitability. The test suite, typecheck, build and fresh local production-build sign-in/editor flow pass after the additional overrides. Before launch, recheck Neon Auth for a supported SDK release and inspect the deployed trace or vendor guidance; remove overrides once the vendor updates its pins.

This narrows the observed deployed exposure but does not prove those packages can never be bundled. Keep the Zod 3 finding open until the app can migrate to a patched major or a documented upstream fix appears. `@neondatabase/auth` remains 0.7.0-beta on npm; Neon says its [managed Better Auth servers](https://neon.com/blog/whats-new-with-the-neon-backend) were patched separately. A pattern scan of 493 tracked/unignored local files found no recognizable live AWS, GitHub, Slack, Stripe, JWT or private-key strings; six generic matches were fixture or error-message constants. `pnpm test`, `pnpm typecheck` and `pnpm build` pass. The isolated backup runner's own npm audit reports four high paths through `@vercel/blob` → OIDC/config → Zod; it accepts only scheduled secrets and provider responses, and has no public request handler. Review that dependency separately before relying on it for Production backups.
